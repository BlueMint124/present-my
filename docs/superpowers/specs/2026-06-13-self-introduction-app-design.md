# 자기소개 웹앱 MVP 설계

## 1. 제품 개요

이 제품은 사용자가 매일 작성한 일기를 바탕으로 자신을 더 잘 이해하고, 그 결과를 캐릭터와 공개 프로필 형태로 보여주는 자기소개 앱이다.

핵심은 "비공개 기록에서 공개 가능한 캐릭터 프로필로"이다. 일기 원문은 프라이빗한 자기이해 공간에 남기고, 외부에 보여주는 것은 사용자가 승인한 캐릭터, 성향, 취향, 대화 주제, 프로필 요약으로 제한한다.

초기 발표 버전은 모바일 앱이 아니라 웹앱으로 제작한다. 발표에서는 핵심 사용자 경험과 향후 수익화 가능성을 보여주고, 실제 모바일 앱은 이후 확장 단계로 둔다.

## 2. 핵심 사용자 경험

사용자는 매일 간단한 질문에 답하거나 자유롭게 일기를 쓴다. 앱은 이 기록에서 감정, 취향, 관심사, 성향 패턴을 분석해 비공개 자기이해 리포트를 만든다.

일정 기간 기록이 쌓이면 캐릭터가 사용자의 성향과 취향을 반영해 변화한다. 이 캐릭터는 사용자가 친구나 다른 사람에게 보여줄 수 있는 공개 프로필의 중심 요소가 된다.

공개 프로필은 자동 공개되지 않는다. AI가 초안을 만들고, 사용자가 공개할 항목을 선택하고 수정한 뒤 공유한다.

## 3. 공개/비공개 원칙

### 비공개 영역

- 일기 원문
- 감정 기록
- 개인적인 자기이해 분석
- 공개 승인 전의 AI 분석 초안

### 공개 가능 영역

- 캐릭터
- 닉네임과 한 줄 소개
- 성향 요약 카드
- 취향 지도
- 나와 잘 맞는 사람
- 대화 시작 추천
- 공유 링크와 명함 카드

공개 프로필에는 사용자가 승인한 항목만 포함한다. 일기 원문이나 민감한 분석 결과는 기본적으로 외부에 노출하지 않는다.

## 4. 발표용 웹앱 MVP 범위

### 실제로 보여줄 핵심 기능

- 메인 대시보드
- 프롬프트 기반 일기 작성
- 샘플 데이터 기반 자기이해 분석
- 주간 캐릭터 업데이트 화면
- 풍부한 공개 프로필 미리보기
- 공유/명함 화면 UI

### UI만 제작할 확장 기능

- 아이템 상점 화면
- 광고 보상 화면
- 결제 안내 화면
- 업적/보상 화면
- 로그인/회원가입 화면
- 앱 확장 로드맵 섹션

결제, 광고, 아이템 구매는 발표용 웹앱에서 실제 기능으로 구현하지 않는다. 대신 향후 비즈니스 모델과 확장 가능성을 보여주는 UI로 제작한다.

## 5. 화면 흐름

1. 홈
   - 오늘 기록 상태
   - 캐릭터 미리보기
   - 이번 주 변화 예고

2. 일기 작성
   - 오늘의 기분
   - 오늘 기억나는 장면
   - 오늘 나답다고 느낀 순간
   - 오늘 좋아했던 것
   - 자유 일기 입력

3. 자기이해 분석
   - 반복 감정
   - 취향 키워드
   - 관심사 변화
   - 성향 패턴
   - 자기소개 초안

4. 캐릭터
   - 주간 업데이트
   - 성향 뱃지
   - 해금 아이템
   - 방 꾸미기 미리보기

5. 공개 프로필
   - 사용자가 승인한 공개 항목
   - 캐릭터 카드
   - 성향 요약
   - 취향 지도
   - 잘 맞는 사람
   - 대화 주제 추천
   - 공유 링크/명함

6. 확장 UI
   - 상점
   - 광고 보상
   - 결제 안내
   - 업적
   - 로그인/회원가입

## 6. 일기 입력 방식

일기 입력은 자유 작성만 두지 않고 질문 프롬프트와 조합한다. 빈 화면에 긴 일기를 요구하면 사용자가 부담을 느끼기 쉽기 때문이다.

기본 입력 항목은 다음과 같다.

- 오늘의 기분
- 오늘 기억나는 장면
- 오늘 나답다고 느낀 순간
- 오늘 좋아했던 것
- 자유 작성란

짧게 작성해도 분석 데이터가 쌓이고, 길게 쓰고 싶은 날에는 자유 작성란을 활용할 수 있게 한다.

## 7. 데이터 활용 구조

### 입력

- 기분
- 기억나는 장면
- 나다웠던 순간
- 좋아했던 것
- 자유 일기

### 비공개 분석

- 반복 감정
- 취향 키워드
- 관심사 변화
- 성향 패턴
- 자기소개 초안

### 공개 결과물

- 캐릭터 외형 변화
- 성향 뱃지
- 취향 지도
- 대화 주제 추천
- 공유 프로필

## 8. 캐릭터 업데이트 주기

캐릭터의 핵심 업데이트 주기는 매주로 한다.

### 매일

일기 작성 완료 후 표정, 말풍선, 기분 색감, 작은 이펙트 정도의 즉시 피드백을 제공한다. 매일 큰 변화를 주지는 않는다.

### 매주

7일치 기록을 묶어 대표 취향, 성향 뱃지, 착용 아이템, 방 소품, 캐릭터 분위기를 업데이트한다. 캐릭터 변화의 메인 주기이다.

### 매월

한 달의 패턴을 바탕으로 자기이해 리포트, 프로필 요약, 공유 카드가 정리된다. 캐릭터의 큰 변화는 특별 이벤트나 월간 리포트와 연결할 수 있다.

## 9. 공개 승인 흐름

1. 사용자가 일기를 작성한다.
2. 앱이 성향, 취향, 캐릭터 변화, 대화 주제를 AI로 제안한다.
3. 사용자가 공개할 항목을 체크하고 문구를 수정한다.
4. 승인된 캐릭터 프로필만 링크, 이미지, 명함 형태로 공유한다.

이 흐름은 프라이버시와 공유 재미를 동시에 지키기 위한 핵심 원칙이다.

## 10. 디자인 톤

디자인 방향은 감성 캐릭터 앱 톤으로 한다.

- 일기 화면은 프라이빗하고 조용하게 구성한다.
- 캐릭터 화면은 귀엽고 생동감 있게 구성한다.
- 공개 프로필은 친구에게 보여주기 좋은 카드형 UI로 구성한다.
- 전체 색감은 따뜻한 베이스에 그린, 코랄, 옐로 포인트를 사용한다.
- 너무 게임처럼 과하지 않게 하되, 캐릭터 성장의 재미는 살린다.

## 11. 발표에서 강조할 메시지

- 사람들은 자신을 소개하라고 하면 막막해하는 경우가 많다.
- 매일의 기록은 자신을 이해하는 가장 자연스러운 데이터가 될 수 있다.
- 이 앱은 일기를 자기소개와 캐릭터 프로필로 바꿔준다.
- 원본 기록은 비공개로 보호하고, 공유되는 것은 사용자가 승인한 결과물뿐이다.
- 발표용 웹앱은 핵심 경험을 보여주고, 이후 모바일 앱과 수익화 기능으로 확장할 수 있다.

## 12. 이후 구현 방향

다음 단계에서는 이 설계를 기반으로 발표용 웹앱 구현 계획을 작성한다. 구현 계획은 화면별 컴포넌트, 샘플 데이터, 사용자 데모 흐름, 테스트 범위를 포함해야 한다.
