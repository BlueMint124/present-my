자기소개 앱: 비공개 기록에서 공개 캐릭터로

일기는 자기이해를 위한 프라이빗 공간으로 두고, 그 결과로 만들어진 캐릭터와 프로필만 친구에게 보여줄 수 있게 확장합니다.

1단계 MVP

비공개로 나를 기록함

일기 작성, 감정/키워드 추출, 자기이해 리포트, 기본 캐릭터 성장.

2단계 유지

캐릭터가 나를 반영함

연속 기록, 캐릭터 변화, 성향 뱃지, 아이템 해금, 간단한 방 꾸미기.

3단계 확장

프로필처럼 보여줌

공개 캐릭터 페이지, SNS 공유, 명함 생성, 꾸미기 아이템, 고급 분석.

공개/비공개 경계

A

일기 원문

절대 비공개입니다. 사용자가 직접 공개하지 않는 한 친구, 검색, 공유 화면에 노출되지 않습니다.

B

자기이해 분석

기본은 비공개입니다. 다만 사용자가 고른 요약 문장, 취향, 성향 뱃지만 공개 프로필에 보낼 수 있습니다.

C

캐릭터/프로필

친구에게 보여주는 공개 결과물입니다. 캐릭터, 방, 뱃지, 한 줄 소개, 공유 링크를 포함합니다.

정리: 제품의 핵심은 "속은 프라이빗, 겉은 공유 가능한 프로필"입니다. 이 경계를 명확히 잡으면 기록의 솔직함과 공유의 재미를 둘 다 살릴 수 있습니다.

공개 캐릭터 카드

나를 닮아가는 캐릭터
감성 탐색가 카페 취향 느긋한 대화 새로운 음식

C형 공개 프로필 구성

  • 나를 설명하는 한 문장일기 데이터에서 뽑은 분위기와 요즘 관심사를 섞어 자동 제안합니다.
  • 성향 요약 카드외향/내향, 계획/즉흥, 감정 표현, 선호 활동 같은 뱃지를 보여줍니다.
  • 취향 지도좋아하는 메뉴, 장소, 음악, 활동, 대화 주제를 카테고리별로 정리합니다.
  • 나와 잘 맞는 사람함께하면 좋은 사람의 성향, 피하면 좋은 소통 방식 등을 부드럽게 안내합니다.
  • 대화 시작 추천친구가 말을 걸기 쉬운 질문이나 주제를 3개 정도 보여줍니다.
  • 공유 링크/명함공개 범위를 선택한 뒤 SNS나 링크로 공유합니다.
1

일기 작성

원문은 비공개 저장. 분석과 추천의 재료로만 사용합니다.

2

AI 초안 생성

성향, 취향, 캐릭터 변화, 대화 주제를 자동으로 제안합니다.

3

사용자 승인

공개할 항목을 체크하고 문구를 직접 수정할 수 있습니다.

4

공유

승인된 캐릭터 프로필만 링크, 이미지, 명함 형태로 공유합니다.

입력

  • 오늘의 기분
  • 기억나는 장면
  • 나답다고 느낀 순간
  • 좋아했던 것
  • 자유 일기

비공개 분석

  • 반복 감정
  • 취향 키워드
  • 관심사 변화
  • 성향 패턴
  • 자기소개 초안

공개 결과물

  • 캐릭터 외형 변화
  • 성향 뱃지
  • 취향 지도
  • 대화 주제 추천
  • 공유 프로필
매일

작은 반응

일기를 쓰면 표정, 말풍선, 기분 색감, 작은 이펙트가 바로 바뀝니다. 핵심 변화보다는 완료 피드백 역할입니다.

매주

핵심 업데이트

7일치 기록을 묶어 대표 취향, 성향 뱃지, 착용 아이템, 방 소품을 업데이트합니다. 캐릭터 변화의 메인 주기입니다.

매월

리포트와 정리

한 달의 패턴을 기반으로 자기이해 리포트, 프로필 요약, 공유 카드가 정리됩니다. 캐릭터 대변신은 선택 이벤트로 둡니다.

발표용 웹앱에서 실제 구현

  • 메인 대시보드
  • 프롬프트 기반 일기 작성
  • 샘플 데이터 기반 자기이해 분석
  • 주간 캐릭터 업데이트 화면
  • 풍부한 공개 프로필 미리보기
  • 공유/명함 화면 UI

발표용 UI만 제작

  • 아이템 상점 화면
  • 광고 보상 화면
  • 결제 안내 화면
  • 업적/보상 화면
  • 로그인/회원가입 화면
  • 앱 확장 로드맵 섹션
01

홈

오늘 기록 상태, 캐릭터 미리보기, 이번 주 변화 예고를 보여줍니다.

02

일기 작성

기분, 기억나는 장면, 나다웠던 순간, 자유 일기를 입력합니다.

03

자기이해 분석

비공개 감정 패턴, 취향 키워드, 성향 요약을 보여줍니다.

04

캐릭터

주간 업데이트, 뱃지, 해금 아이템, 방 꾸미기 미리보기를 제공합니다.

05

공개 프로필

사용자가 승인한 항목만 캐릭터 프로필과 공유 카드로 만듭니다.

06

확장 UI

상점, 광고 보상, 결제, 업적 화면을 발표용 UI로 보여줍니다.

디자인 톤: 감성 캐릭터 앱

프라이빗한 일기 감성과 캐릭터 성장의 재미를 함께 살리는 방향입니다. 너무 게임처럼 과하지 않고, 발표에서 제품성이 잘 보이도록 부드럽고 생동감 있게 잡습니다.

색감

따뜻한 베이스에 그린, 코랄, 옐로 포인트.

캐릭터

처음엔 단순하고, 기록이 쌓일수록 개성이 생김.

UI

카드형 정보, 부드러운 상태 변화, 쉬운 공유 버튼.

무드

혼자 기록할 때는 조용하게, 공유할 때는 밝게.
